Fonctionnalités principales

Widget personnalisable

Intégrez le widget en 2 minutes avec un simple snippet JavaScript. Personnalisez entièrement l'apparence (couleurs, position, textes, langue) pour matcher votre charte graphique. Compatible avec tous les frameworks modernes.

  • ✓ React, Vue, Angular, Svelte
  • ✓ Vanilla JavaScript
  • ✓ TypeScript support

Système de votes

Permettez à vos utilisateurs de voter pour les idées qu'ils préfèrent. Identifiez rapidement les fonctionnalités les plus demandées et évitez de développer des features qui n'intéressent personne.

  • ✓ Votes illimités
  • ✓ Classement automatique
  • ✓ Historique des votes

Priorisation intelligente

Notre algorithme analyse automatiquement les votes, l'impact potentiel et l'effort estimé pour vous suggérer les meilleures priorités. Tags automatiques et tableaux de bord personnalisables.

  • ✓ Scoring automatique
  • ✓ Tags intelligents
  • ✓ Vues personnalisées

Notifications temps réel

Recevez des alertes instantanées par email ou Slack pour chaque nouveau feedback. Suivez l'évolution du statut des demandes et tenez vos utilisateurs informés avec un changelog automatique.

  • ✓ Alertes Slack & Email
  • ✓ Suivi de statut
  • ✓ Changelog public

Intégrations natives

Synchronisation bidirectionnelle avec vos outils de gestion de projet préférés. API REST complète, webhooks pour automatiser vos workflows, et connexion Zapier pour 5000+ applications.

  • ✓ Jira, Trello, Asana, Linear
  • ✓ API REST & Webhooks
  • ✓ Zapier & Make.com

Sécurité & conformité

Données hébergées en Europe avec conformité RGPD complète. Authentification SSO/SAML disponible, chiffrement de bout en bout, et contrôle d'accès granulaire par équipe et projet.

  • ✓ RGPD compliant
  • ✓ SSO & SAML
  • ✓ Chiffrement SSL/TLS

Fonctionnalités avancées

Filtres et recherche avancée

Filtrez vos feedbacks par statut, type, projet, date, votes ou tags. Recherche full-text instantanée pour retrouver n'importe quel feedback en quelques secondes.

Gestion d'équipe

Invitez votre équipe, assignez des rôles et permissions, créez des équipes par projet. Chaque membre voit uniquement ce qui le concerne.

Rapports et analytics

Tableaux de bord avec métriques en temps réel : volume de feedbacks, tendances, satisfaction utilisateur, taux de résolution. Exportez vos données en CSV ou PDF.

Multi-langue

Interface disponible en 15+ langues. Le widget s'adapte automatiquement à la langue du navigateur de l'utilisateur. Traduction automatique des feedbacks disponible.

Applications mobiles

SDK natifs pour iOS et Android. Intégrez le feedback directement dans vos apps mobiles avec la même simplicité que le web.

Captures d'écran et pièces jointes

Les utilisateurs peuvent joindre des screenshots, vidéos ou fichiers à leurs feedbacks. Annotation d'images intégrée pour pointer précisément les problèmes.
