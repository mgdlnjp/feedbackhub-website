Documentation FeedbackHub

Tout ce dont vous avez besoin pour intégrer et utiliser FeedbackHub

Démarrage rapide

Intégrez le widget FeedbackHub à votre application en moins de 3 minutes.

1 Obtenez votre clé API

Connectez-vous à votre dashboard FeedbackHub et copiez votre clé API depuis les paramètres du projet.

// Votre clé API ressemble à ceci
const API_KEY = 'fbh_live_1234567890abcdef';

2 Ajoutez le script à votre page

Copiez ce code juste avant la balise </body> de votre HTML.

<!-- FeedbackHub Widget -->
<script src="https://cdn.feedbackhub.com/widget.js"></script>
<script>
  FeedbackHub.init({
    apiKey: 'VOTRE_CLE_API',
    position: 'bottom-right', // 'bottom-right', 'bottom-left', 'top-right', 'top-left'
    primaryColor: '#2563EB',
    language: 'fr' // 'en', 'fr', 'es', 'de'...
  });
</script>

✓ C'est tout !

Le widget est maintenant actif sur votre site. Vos utilisateurs peuvent cliquer dessus pour envoyer leurs feedbacks.

API REST

Authentification

Toutes les requêtes API nécessitent votre clé API dans le header Authorization.

curl https://api.feedbackhub.com/v1/feedbacks \
  -H "Authorization: Bearer VOTRE_CLE_API"

Récupérer les feedbacks

GET /v1/feedbacks 
// Requête
fetch('https://api.feedbackhub.com/v1/feedbacks', {
  headers: {
    'Authorization': 'Bearer VOTRE_CLE_API'
  }
})

// Réponse
{
  "feedbacks": [
    {
      "id": "fb_123abc",
      "type": "feature",
      "title": "Mode sombre",
      "description": "Il serait génial d'avoir un dark mode",
      "votes": 47,
      "status": "planned",
      "created_at": "2025-01-15T10:30:00Z"
    }
  ],
  "total": 156,
  "page": 1
}

Créer un feedback

POST /v1/feedbacks 
fetch('https://api.feedbackhub.com/v1/feedbacks', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer VOTRE_CLE_API',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    type: 'bug',
    title: 'Erreur au chargement',
    description: 'La page ne charge pas sur Safari',
    user_email: 'user@example.com'
  })
})
